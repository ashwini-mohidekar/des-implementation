# DES Algorithm Implementation

This repository contains a step-by-step implementation of the Data Encryption Standard (DES) algorithm in Python using Jupyter Notebook.

## Features
- Manual implementation (no cryptographic libraries)
- Clear explanation of each step
- Includes key generation, Feistel function, and full encryption
- Multiple test cases demonstrating DES behavior

## Files
- DES_Implementation.ipynb – main notebook
- DES_Implementation.pdf – exported version

## Concepts Covered
- Permutation and substitution
- Feistel structure
- Round key generation
- Avalanche effect
